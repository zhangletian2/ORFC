# 阶段一计划 v10：算法桥接与联合学习三臂比较

日期：2026-07-31　　前置：v9（N5–N7，`unseal.json` `verdict: PASS`）
状态：**预注册**。本文件在任何 v10 代码产生结果之前写成；此后改动任一常数
即为新版本（v11），不是补丁。

---

## 0. 本轮回答什么

v9 证明了一件事、且只证明了一件事：在 `(U₀,Θ₀)` 冻结、名义码率整数相等时，
**存在**一个一比特非均匀分配严格优于均匀（R64 −1.600%，R96 −1.227%，
Holm FWER=.05 双双 PASS）。它没有学习任何东西。

v10 把「存在」推进到「可学习」，分两个不能合并的步骤：

**B（桥接）**——区分两件被经常混同的事：

  非均匀收益确实存在　　vs　　拟采用的优化器能否找到该收益

固定 v9 的 `(U₀,Θ₀)`，让**将来要用在外层的那个分配优化器**从均匀点出发，
只在 cal-500 上搜索，在 v9 从未使用过的 dev-500 上以 hard 完整 tail 失真验收。
它必须找出至少一个优于均匀点的同码率分配。**桥接不过就停在 B**，
不进入 C；换一个优化器 = 新版本，不是在本轮里调参重试。

**C（三臂）**——桥接通过后，比较：

| 臂 | 分配 | 训练 | 步数 |
|---|---|---|---|
| **A1 `uniform-equal-step`** | 固定均匀 | 联合训练 `U,Θ` | `N_inner` |
| **A2 `nonuniform-joint`** | 外层 hard 一比特交换更新 | 内层联合训练 `U,Θ` | `N_inner` |
| **A3 `uniform-equal-compute`** | 固定均匀 | 联合训练 `U,Θ` | `N_inner + ΔN` |

A1 与 A2 的初始化、batch 顺序、学习率表、随机种子**完全一致**，唯一差别是
前向用的分配向量。ΔN 在正式训练前由 C0 profiling 按 FLOPs 对齐 A2 定死，
**不得依据结果调整**。

**主结论**（唯一的确认性检验）：

$$d_{R,n} \;=\; D_n(\text{A2}) \;-\; D_n(\text{A1}),\qquad n=1..500$$

在 holdout-500 上逐图配对，R64/R96 两个锚点构成一个族，Holm 控制 FWER=0.05。
它直接检验**非均匀分配机制本身**是否带来额外收益。

**次要（记录项，不是判据）**：`D(A2) − D(A3)`（等算力稳健性）、
外层扫描的 FLOPs 成本、`D(A1)` 相对 v9 冻结均匀点的改善、
`D(A2)` 相对 v9 冻结候选的改善、真实熵率 `R_ψ`。

## 3. Stage B：桥接

### 3.1 优化器（这就是 A2 的外层，逐字相同的代码路径）

```
m ← uniform
for t = 1 .. S_OUTER_MAX:
    C(m) = { 从 m 出发的所有合法一比特交换 :
             down i 需 m_i > 0, up j 需 m_j < 2, i ≠ j }        # 均匀点处 |C| = 992
    在 cal-500 上对 C(m) 逐个算 hard 完整 tail 失真（逐图，再取图均值）
    m' ← argmin，按 TIE_BREAK 破平
    若 mean D(m') < mean D(m) − EPS_ACCEPT_MULT · REPLAY_REL_TOL · mean D(m):
        m ← m'
    否则 stop
```

每一步都断言 `nominal_rate(m) == anchor.rate`（整数精确）。
菜单只有 3 档，所以每组相对均匀最多 ±1 比特——这不是本轮的约束瓶颈
（受约束的是 `S_OUTER_MAX`，不是菜单宽度）。

### 3.2 一条免费的重放不变量

`t=1` 的 argmin 必须**精确等于** v9 冻结的候选（R64 down g24 up g7；
R96 down g15 up g26），且 992 个 cal 均值必须与 v9 的 `cal_distortion.npy`
在 `REPLAY_REL_TOL` 内逐点一致。不一致 ⇒ `INVALID_EXPERIMENT`：
说明这套栈相对 v9 已经移动，后面所有比较都不可信。

### 3.3 验收（真正的闸门）

在 **dev-500** 上对 `uniform` 与 `m_final` 各算一次 hard 完整 tail 失真，
逐图配对差 → bootstrap 100,000 → 单侧 p → Holm（族 = 两锚点）→ UCB。
UCB 与 p 取自同一条 bootstrap 分布，所以「p < α」与「UCB < 0」是同一句话。

- **两个锚点都通过** ⇒ 进入 C，族 = {R64, R96}；
- **只有一个通过** ⇒ 只有该锚点进入 C，族 = 单锚点（Holm 退化为单次检验），
  另一锚点的失败按事实记录。族的大小由 B 的结果决定，而 B 在 C 之前完成，
  所以族在 C 开始时已经固定，不存在事后选择；
- **两个都不通过** ⇒ **停在 B**。写节点记录，不进入 C。

### 3.4 成本

一次全邻域 cal 扫描 = 992 × 500 = 496,000 次 tail 前向 ≈ **4.9 min**
（v9 实测 1,690 img/s，config.py 的 profiling 表）。
最多 8 步 ⇒ ≤ 40 min/锚点；两锚点并行（GPU 2、3）⇒ 墙钟 ≈ **40 min**。

## 4. Stage C：三臂

### 4.1 内层：hard 直通估计（STE），没有温度

v8 死在 M3，链条是：菜单闸门 → 依赖预训练 → 依赖 τ → soft–hard 代理间隙。
v10 从根上切断这条链——内层前向**就是**评测前向：

```
z   = y @ U                                     # y = per_image 归一化特征
ĉ_g = codebook_{m_g}[ argmin_k ‖z_g − c_k‖² ]   # 硬最近邻，argmin 不回传
ẑ_g = ĉ_g + z_g − z_g.detach()                  # 前向恒等于 ĉ_g
x̂   = inv_normalize(ẑ @ Uᵀ)
loss = mean_n ‖tail(x̂_n) − teacher_n‖²
```

`ẑ = ĉ + z − sg(z)` 这一步同时给出两条梯度：
`∂ẑ/∂z = I`（STE，`U` 拿到梯度）与 `∂ẑ/∂ĉ = 1`（被选中的码字拿到**任务**梯度）。
没有 τ、没有退火、没有 soft 分支，**训练损失与终点指标是同一个量**。

这也自带诊断：若 STE 的梯度无用，hard 训练损失根本不会下降，
不需要任何代理就能立刻看出来（见 G1）。

现有 `soft_pq.SoftPQ._quantise` 的直通路径是 `τ>0` 的 softmax-ST，
`τ=0` 时退化为纯 gather（`U` 拿不到梯度）。v10 **不修改** `../orfc/soft_pq.py`，
在 `phase1/v10/qhard.py` 里新写这个前向，复用 codec 里的码本与旋转张量。

- `U`：`cayley.DirectOrthogonalTransform` + `cayley.CayleySGD`（`reorthogonalize_every=100`）；
- `Θ`：Adam；
- 死码规则（三臂逐字相同）：每 `T_dead` 步，窗口内零分配的码字重置到该组当前
  量化误差最大的向量上；计数记录，不设闸门。

### 4.2 外层（仅 A2）

每 `T_outer` 个内层步，用 §3.1 的**同一个** `search.py`，以当前 `(U,Θ)` 在 cal-500 上
做一次全邻域扫描，最多接受一次交换。每次外层事件后断言名义码率仍等于 `anchor.rate`。

### 4.3 开封前必须先过的闸门（全部只用 train/cal，不花终点集）

| 闸门 | 内容 | 不过怎么办 |
|---|---|---|
| **G1 内层可用性** | A1 在 **train-core** 上的 hard D 必须比 `(U₀,Θ₀)` 严格下降 > 100 × 噪声底 | 学习器坏了，C 作废，不开封 |
| **G2 码率精确** | A2 任一时刻用过的每个分配，整数名义码率 == `anchor.rate` | `INVALID_EXPERIMENT` |
| **G3 正交性** | `‖UᵀU−I‖_F`（float64）全程 < 1e-5 | `INVALID_EXPERIMENT` |
| **G4 匹配是真的** | A1 与 A2 在前 `T_outer` 步必须逐比特同态（同种子、同顺序、同分配） | `INVALID_EXPERIMENT` |

G4 是把「相同预算/相同初始化」从一句话变成一条可执行断言。

### 4.4 两条必须写明的不对称（不是缺陷，是方法的一部分）

1. **参数量不等**。同名义码率下非均匀用的码字总数更多
   （R64 均匀 32×4 = 128 个码字；一次交换后 128 − 2 + 4 = 130），
   因为 `2^b` 是凸的。名义码率才是被固定的资源，参数量不是；如实报告，
   并在记录项里给出码本存储字节数。
2. **A2 额外消耗 cal-500 作为搜索资源**，A1/A3 不用它。这是方法成本的一部分，
   与外层 FLOPs 一起报告，不做隐藏。

### 4.5 A3 的已知混淆

FLOPs 对齐意味着 `ΔN` 很大：一次扫描 ≈ 496,000 次前向 ≈ 165,000 次
「前向+反向」等效，8 次扫描 ≈ 1.32M 等效 ⇒ 以 batch 16 计 `ΔN ≈ 8×10⁴` 步，
即 train-core 上数百个 epoch。**A3 很可能过拟合**。
这不是要靠调小 `ΔN` 掩盖的问题——`ΔN` 由 C0 按 FLOPs 定死。
处理办法是把 A3 的 cal 曲线作为记录项画出来，让过拟合可见，
并在解释 A3 结果时明确：A3 回答的是「同算力下多训练能否达到同样收益」，
若 A3 因过拟合而更差，结论只能是「多训练不是替代品」，
不能加强为「非均匀收益不可能被更多训练复制」。

### 4.6 成本

内层 `fwd+bwd` ≈ 560 img/s（前向 1,690 img/s 的 1/3）。
`N_inner = 12,000` × batch 16 = 192,000 图次 ≈ **6 min**。
A2 = 6 min + 8 × 4.9 min ≈ **46 min**。A3 ≈ **45 min**。
六次运行（2 锚点 × 3 臂）在 GPU 2/3/4/7 上并行 ⇒ 墙钟 ≈ **1.5 h**。
（`N_inner` 等以 C0 实测为准，以上为下限估计。）

VRAM：train-core 常驻 4.2 + 4.2 = 8.4 GB，cal-500 常驻 1.06 GB，
batch 的 tail 激活约 1–4 GB ⇒ 12–14 GB / 24 GB（RTX 4090）。
C0 profiling 选取在 20 GB 以内、吞吐最高的 batch。

## 8. 本轮结束时**不能**声称的

无论结果如何，以下四条在 v10 结束时仍然不成立，写论文时不得越界：

1. **不是「优于 ORFC」**。v10 比较的是两个内部臂，不是 ORFC 基线；
   且名义码率相等 ≠ 熵编码后码率相等，`R_ψ` 只作记录项。
2. **不是全局最优分配**。外层是贪心一比特交换，最多 8 步，
   搜索域远小于 𝒜_R。
3. **不外推到其他层 / 码率 / backbone**。两个锚点的组重要性排序本身就不一致。
4. **A3 不构成「更多训练无法达到同样效果」的证明**（见 §4.5）。
