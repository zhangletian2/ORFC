# 阶段一计划 v13：精确预算下的候选档位持续训练

日期：2026-08-02  
状态：V13-A、V13-B 与 100 epoch 正式训练均已完成；远程 commits `05c5011` / `001c6b0`，正式运行 `v13_coverage_full_20260802T021748Z`。

## 1. 目标

修正 v12 的组–档位坍缩，使策略确定前的每个可行候选档位都持续适应当前 \(U\)，避免用陈旧码本的失真误判候选分配。

## 2. 精确预算覆盖

每个训练步构造两类分配：

\[
\mathcal A_{\rm pol}\sim p_\psi(\mathbf m\mid R),\qquad
\mathcal A_{\rm cov}\sim q_{\rm cov}(\mathbf m\mid R).
\]

- `policy` 样本保持 v12 的精确预算 DP 采样。
- `coverage` 样本按固定周期遍历组–档位对：强制目标组使用目标档位，其余组由同一 DP 的条件分布补全，保证每个样本都严格满足总码率。
- 覆盖顺序与当前策略概率无关，因此可给出有限周期内的确定覆盖保证。

联合损失保持原始尺度：

\[
L_{\rm codec}=(1-\lambda_{\rm cov})
\overline D(\mathcal A_{\rm pol})
+\lambda_{\rm cov}\overline D(\mathcal A_{\rm cov}).
\]

该损失更新 \(U\) 和码本。策略损失只由
`policy` 样本的 hard tail MSE 和 log-probability 计算，
`coverage` 样本不进入 REINFORCE，因此不引入离策略偏差。

## 3. 实现约束

1. 默认关闭覆盖，保持现有 v12 命令完全等价。
2. 覆盖样本数、损失权重和覆盖时长显式记录。
3. 分开记录 on-policy 访问次数、强制覆盖次数和实际码本梯度覆盖。
4. 所有覆盖分配逐项审计名义总码率。
5. 本节只实现和单元测试，不直接启动正式训练。

## 4. 验证节点与 Exit

### V13-A：合同测试

- 强制的组–档位与生成分配一致；
- 每个分配总码率精确等于 \(R\)；
- 一个完整周期覆盖全部可行组–档位对；
- 覆盖损失不向策略 logits 传梯度。

Exit：任一条失败时只修正实现，不启动训练。

### V13-B：短程因果验证

在同一 ORFC Cayley-Adam 设定下比较 v12 和覆盖版，只判断：

1. 最后窗口的组–档位梯度覆盖是否由 0 变为正值；
2. 候选档位在 \(U\) 变化后是否仍有码本漂移；
3. hard MAP 验证失真是否与 v12 同步下降。

Exit：覆盖不成立或 hard MAP 失真持续恶化时，停止该路线；两者同时成立才进入完整训练。

执行结果：PASS。短程与完整训练均实现正的末窗口组–档位梯度覆盖；正式训练中每个组–档位被强制覆盖至少 162 次，全部码本发生更新。R64/R96 最终 hard MAP MSE 为 297,404.2/234,479.5，两个分配均通过固定共享 codec 下的一步交换局部最优审计。

下游结论：覆盖版相对原始 ORFC 在 R96 上仍取得一致收益；相对无覆盖 v12，则 R96 分类更高但 Tail MSE 和分割略低，R64 的 mIoU 恢复但分类与 Tail MSE较低。覆盖机制完成了候选档位持续训练这一方法学修正，但没有形成对 v12 的全指标支配。

## 5. DP-ST 独立复验

在覆盖路线验证后，允许 `DP-ST + ORFC Cayley-Adam` 作为独立对照。需同时报告 hard MAP 失真、最后梯度覆盖、策略熵，以及 DP 梯度对真实固定码率交换差分的排序相关性。该对照用于区分 Cayley-SGD 影响与 DP-ST 代理偏差，不与覆盖路线混合选参。
