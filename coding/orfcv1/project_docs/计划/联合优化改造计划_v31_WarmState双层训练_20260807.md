# V31：Warm-State 排序与双层联合训练正式协议

## 目标与继承关系

V31 继承 V30 父节点条件化层次残差树的容量门 PASS。V30 的排序门使用 fresh Adam，且旧双层实现复用 cost-table 数据做短适配，二者与正式 warm-state 外层更新语义不一致；因此 V30 的 R64/R96 排序结果仅作历史诊断，不能授权 V31 正式训练。

V31 验证三个有限结论：层次共享缓解候选成熟度偏差；内层单路径减少每步计算；共享权重排序在注册候选池和固定短适配预算下筛选独立适配后的优良候选。

## 数据合同

- `train-fit=5000`：主训练；
- cost table：train-fit 中固定 512 图；
- candidate adaptation：随后固定 128 图，按固定顺序恰好组成 8 个无重复 batch（batch=16）；
- `validation-select500`：排序、外层接受和内部训练合同验收；
- `validation-rest2500`：冻结 checkpoint 后一次性最终验收；
- 分类和分割使用各自冻结测试口径。

512/128 是两个训练侧估计器，500 是唯一选择集。任何扩大样本、步数或候选集合的改变均需升级协议版本。

## 优化与 scheduler 合同

完整可回滚状态为
\[
\mathcal Z=(\mathbf m,\pi,U,\Theta,
\operatorname{Adam}_{\pi},
\operatorname{Adam}_{\rm codec},
\operatorname{scheduler}).
\]

codec 使用按实际提交更新计数的截断 cosine schedule：
\[
T_{\max}=5000+500+10\times8=5580.
\]
5000 是主内层步骤，500 是最终硬分配微调，最多 10 次外层事件各提交 8 个候选适配步骤。到达 `T_max` 后学习率保持为零。

候选分支复制相同 codec、codec Adam 和 scheduler state，并沿当前 schedule 连续执行 8 步。拒绝分支不推进共享计数；接受分支提交其 Adam moments 和 scheduler 计数。policy MAP 实现失败时，policy logits 与 policy Adam moments 也必须回滚。

## T1：排序授权运行

排序授权从正式 coverage checkpoint 独立运行：

1. 确定性执行 500 个内层步骤：前 300 步严格公平覆盖，后 200 步按初始精确预算策略采样；
2. 保存 step-500 codec、policy、两个 Adam 和 scheduler state；
3. 由 512 图 cost table 构造 DP Top-8 与 8 个固定 seed 随机候选；记录去重后的实际候选数；
4. 每个候选从同一 warm state 分叉，在固定 128 图的相同 8 个 minibatch 上适配；
5. 在同一 `validation-select500` 上硬量化评测共享分数和适配后分数；
6. Spearman 使用并列值平均秩。

排序 PASS 要求
\[
\rho_{\rm Spearman}\ge0.8
\]
且独立适配后的最优候选位于共享权重 Top-8。R64/R96 必须同时 PASS。授权运行完成后丢弃全部训练状态。

## T2：正式重放 parity

正式训练重新从同一个 coverage checkpoint 出发，不接续 T1 状态，并确定性重放相同前 500 步。第一次外层事件必须与 T1 满足：

- 分配、候选池和 Top-K 完全一致；
- codec、policy、optimizer/scheduler 计数满足注册的数值 parity；
- 共享评分满足注册浮点容差。

具体口径为：所有离散对象、候选顺序和 scheduler/optimizer step 计数精确一致；codec、policy 与 Adam 浮点张量逐对象相对 Frobenius 误差不超过 `1e-7`；共享评分的最大逐候选相对误差不超过 `1e-6`。这些容差不得在重放后调整。

parity 失败属于实现失败，正式训练终止。

## T3：正式双层训练

- 主训练 5000 步；前 300 步严格公平覆盖，之后为策略单路径分配；
- 每个内层 minibatch 仅使用一个精确预算分配和一次 Tail 前向；
- 每 500 步执行外层事件，外层额外 Tail 前向、短适配前向和墙钟成本单独统计；
- 每次重新构造局部候选并计算 Spearman；T1 PASS 不永久授权后续事件；
- incumbent 强制进入 successive-halving Top-4；
- 仅当
  \[
  \rho_t\ge0.8,\qquad
  D_t(\mathrm{winner})<D_t(\mathrm{incumbent})
  \]
  时允许提交；
- 接受时原子提交 winner 的 allocation、U、树码本、codec Adam、scheduler，并更新 policy 与 policy Adam；MAP 未实现则整体回滚；
- 最终固定硬分配，联合微调 U 与树码本 500 步。

## T4：固定均匀控制

控制组从同一个 coverage checkpoint 和相同完整状态出发：

- 前 300 步重放与 V31 完全相同的严格公平覆盖；
- 后 4700 步固定使用均匀分配；
- V31 每接受一次 winner，控制组在相同事件位置用相同 8 个 minibatch 和学习率补偿 8 步均匀更新；
- 使用相同最终 500 步微调、optimizer 和 scheduler 计数。

两组允许各自更新 U 与树码本。唯一机制差异是正式阶段是否更新非均匀分配。候选筛选的未提交计算不向控制组补偿，但必须单独报告为方法搜索成本。

## T5：内部 PASS

`validation-select500` 上必须同时满足：

1. 精确总码率；
2. `final Tail MSE < initial Tail MSE`；
3. 至少一次 winner 的完整状态被原子提交；
4. 每个外层接受事件均满足事件级 Spearman 与严格改善；
5. \(\min_{g,m}\mathrm{exposure}^{\rm warmup}_{g,m}\ge100\)；
6. 报告各档叶节点使用率和 zero-use centroid；
7. \(D_{\rm V31}^{\rm select}<D_{\rm uniform}^{\rm select}\)。

任一条件失败，内部结论为 FAIL，不打开 held-out 数据。

## T6：最终 held-out 验收

内部 PASS 后冻结两个 checkpoint，并一次性在 `validation-rest2500` 上计算逐图差值
\[
\Delta_i=D_i(\mathrm{V31})-D_i(\mathrm{uniform}).
\]
只有配对单侧 95% 置信上界严格小于零，才能声称非均匀联合训练优于固定均匀控制。若未通过，不回调参数、不扩大样本、不改变门限，仅报告未泛化。随后进行冻结分类和分割评测。

置信上界使用 10,000 次逐图配对 bootstrap，固定 seed `20260807`，统计量为 \(\overline\Delta\)。

## FAIL 处理与结论边界

任一门 FAIL 时，先检查 checkpoint 血缘、预算、候选对应、数据顺序、状态复制、硬评测、平均秩、原子提交与确定性重放。只修复可证明的实现错误；实现正确仍 FAIL 则停止后续门，不降低阈值。

最终不声称恢复全部分配空间上的独立完全重训排序，也不声称获得全局最优分配。
