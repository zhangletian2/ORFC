# 联合优化改造计划 v22：确定性 DP 与同目标块坐标更新

日期：2026-08-06

## 目标

在 DINOv2 ViT-L/14 `blk20/R64` 上，使用更可解释、低方差且更高效的方式联合优化非均匀分配、正交表示和多档码本。第一轮只回答：确定性分配块能否在不依赖 REINFORCE、公平损失和策略熵的情况下，稳定降低固定码率下的完整 hard tail 目标。

## V21 当前方法与证据

V21 每步执行：

1. 精确预算策略分布采样 4 个分配；
2. 另外构造 3 个 strict-fair 分配，使每个组–档位每步出现一次；
3. 以
   \[
   L_{\rm codec}=L_{\rm policy}+0.25L_{\rm fair}
   \]
   同步更新 \(U\)、全部被覆盖码本和 ECVQ prior；
4. 用 REINFORCE leave-one-out 更新分配 logits，并使用初始权重 \(10^{-2}\) 的熵正则；
5. 码字层使用 hard forward、soft-assignment backward，温度从 0.5 降到 0.005。

`blk20/R64` 的正式结果为：

- 15,600 步、batch 32、ORFC Cayley-Adam，\(lr_U=lr_\Theta=3\times10^{-4}\)；
- MAP hard tail MSE 从 707,459.4 降至 296,848.3；
- 策略熵从 32.70 降至 0.073，最终分配为非均匀；
- policy marginal 最小值为 \(3.4\times10^{-6}\)，策略在训练后期几乎完全退化；
- strict-fair 使所有组–档位每步都有梯度，但公平分配始终以 0.25 权重改变 \(U\) 与码本的优化目标；
- 固定最终 codec 的 824 个两组码率转移中没有更优邻居；这只证明冻结参数下的局部稳定，不证明逐分配重训 oracle；
- 现有严格同图结果显示当前方法在 `blk20/R64` 的 Tail MSE 比 ORFC 低 1.72%，因此联合学习具备正信号，但仍缺少分配机制的理论闭环。

## 主要改进方向

### A. 分配变量

去掉训练式策略分布、REINFORCE、leave-one-out、公平分配损失和策略熵。分配变为外层确定性块：

1. 固定当前 \(U,\Theta\)；
2. 在固定校准子集上计算每个组切换到各档位的完整 hard tail 代价；
3. 用精确预算 DP 求可分代理的最优分配，并保留 top-\(K\)；
4. 对 top-\(K\) 使用完整 hard tail 目标重评；
5. 只有候选完整目标优于当前分配才接受。

### B. 正交表示与码本

固定已接受分配后，沿用 ORFC Cayley-Adam、ECVQ 目标和 hard-forward/soft-codeword-backward，更新 \(U\)、当前分配使用的码本与 prior。候选档位不通过公平 tail 损失共同拉动 \(U\)。

未选档位的可比性分两步处理：

- 初步实验直接复用 V21 已经由全档 K-means 初始化的码本；
- 若外层更新后候选档位明显陈旧，再增加只更新候选组–档位码本的局部适配，不重新引入全分配公平损失。

### C. 真实目标与代理关系

单组代价只是一阶离散局部模型。每轮必须同时记录：

- 代理预测的候选收益；
- 完整 hard tail 目标的实际收益；
- top-\(K\) 是否包含实际最佳候选；
- 单组模型在随机精确预算分配和邻域候选上的排序与残差。

若候选被完整目标拒绝，保持当前分配，不允许代理更新恶化真实目标。

## 实现阶段

### V22-S0：只读/离线分配块验证

输入 V21 `blk20/R64` 冻结 checkpoint，在 64 张独立校准图上：

1. 构造 32×3 的单组档位代价表；
2. 精确 DP 求 R64 分配和 top-\(K\)；
3. 用完整 hard tail MSE 重评；
4. 与 V21 MAP、均匀分配和全两组邻域比较。

通过条件：DP 候选可复现或改进冻结 codec 的真实低失真分配，代理预测与实际收益方向一致。失败时不进入训练，先分析组间 mixed difference。

### V22-S1：短程块坐标训练

- `blk20/R64`、训练集 5k、验证集 500；
- 采用一个当前硬分配训练 \(U\)、激活码本与 prior；
- 每个外层周期在固定校准子集刷新代价表并做一次 DP/完整目标验收；
- 先运行少量外层周期，15 分钟检查一次；
- 记录 wall time、GPU 利用率、峰值显存和 tail 前向吞吐。

通过条件：

1. 每次接受的分配在验收集上完整 hard 目标严格下降；
2. 固定分配的参数更新不会系统性提高同一完整目标；
3. 最终 hard tail MSE 低于初始化和 V21 同步训练的匹配短程点；
4. 被激活码本持续获得梯度；最终激活档不存在严重 centroid collapse；
5. DP 代理与完整目标的候选排序没有持续反向。

### V22-S2：完整训练与下游评测

S1 通过后运行 100 epoch 完整训练，每小时检查一次。完成后审计：

- 精确名义码率 R64 与实际 ECVQ/rANS 码率；
- hard parity、正交误差、分配轨迹和全邻域交换；
- 激活码本码字使用率与 dead centroids；
- Tail MSE、ImageNet 分类和 VOC 分割；
- 与 V21 和原始 ORFC 在相同 checkpoint、图像集合和评价口径下比较。

## Exit

- **进入完整训练**：S1 同时满足真实目标下降、代理方向有效和码本健康。
- **修正代理**：单组模型排序失败，但失败集中在少量组对；增加活动组 pairwise mixed-difference 后重新执行 S0/S1。
- **停止可分 DP 路线**：单组与稀疏二组模型均无法覆盖完整目标的候选排序；结论为当前 tail 的分配交互不能由低阶代价表支持，回到完整目标上的其他结构化离散优化。
- **进入下游评测**：完整训练的同图 Tail MSE 优于 ORFC/V21，且审计无选择早停或激活码本坍缩。
