# 联合优化改造计划 v23：候选码本内层适配

日期：2026-08-06

## 问题

V22 用确定性 DP 替代策略采样，但只训练当前分配的码本。100 epoch 中 63 次外层事件只接受起点分配；未选档位相对已训练档位持续陈旧，使分配比较在长程中失去可比性。

## 目标

近似 oracle 中“候选参数充分优化后再比较”的内层，同时不让候选分配改变共享正交表示的训练目标。

## 非对称梯度路由

当前主分配为 \(\mathbf m_t\)。每个 minibatch 执行：

1. **主更新**

   \[
   J(\mathbf m_t,U,\Theta)
   \]

   正常反向，更新 \(U\)、当前被选码本和 prior。

2. **候选适配**

   按确定性轮询选取一个当前未选的组–档位 \((g,k))，构造局部替换 \(\mathbf m_t^{g\leftarrow k})。候选损失使用完整 hard tail ECVQ 目标，但只取其对 \(\Theta_{gk}) 与对应 prior 的梯度：

   \[
   \Theta_{gk}^{+}
   =
   \Theta_{gk}
   -\eta\nabla_{\Theta_{gk}}
   J(\mathbf m_t^{g\leftarrow k},
   \operatorname{stopgrad}(U),\Theta).
   \]

   共享 \(U\)、其他组和其他码本不接收候选损失梯度。

3. **分配更新**

   周期性重新测量组–档位代价，用精确预算 DP 求 top-K，只接受完整 selection 目标下降的分配。

候选替换单独可以暂时不满足总预算；它只用于适配一个局部码本。所有正式分配选择和报告仍由 DP 严格满足总码率。

## 效率

每步一次主分配 tail 前向和一次候选 tail 前向，理论开销约为 V22 的 2 倍，仍明显低于 V21 每步 4 个策略分配 + 3 个公平分配。候选对按轮询覆盖，不需要 REINFORCE、leave-one-out、策略熵或公平损失权重。

## 实验与 Exit

### S0/S1

- `blk20/R64`；
- V22 和 V23 从同一初始 codec 出发，各 1,000 步；
- 外层每 250 步更新；
- 相同 calibration/selection/report 分割和种子。

进入完整训练的条件：

1. 所有当前未选组–档位获得非零候选梯度；
2. 候选损失对 \(U\) 的梯度注入为零；
3. 第 250 步之后仍可出现 selection/report 方向一致的有效分配更新，或 V23 的最终独立 report 目标显著优于匹配 V22；
4. hard-parity、正交误差和 centroid 使用审计通过；
5. V23 总运行时间仍低于 V21 匹配步数的时间。

若候选码本获得梯度但分配仍锁死，则将候选适配从轮询单替换升级为“DP top-K 候选的少量内层 unroll”；若这一步仍失败，转向嵌套/残差多码率码本。
