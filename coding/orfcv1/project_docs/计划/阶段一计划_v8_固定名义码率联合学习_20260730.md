# ORFC Extension 计划 v8：**阶段一 = 固定名义码率下的联合学习**

## Context

本轮只回答一个干净的问题：

> **在固定名义总码率下，联合学习 \(U\)、多模式码本与组级非均匀分配，
> 能否稳定获得均匀分配无法达到的完整 ViT tail 失真收益。**

**阶段一目标（唯一）**：

\[
\boxed{\ \min_{U,\Theta,\mathbf m}\ D_{\mathrm{tail}}(U,\Theta,\mathbf m)
\quad\text{s.t.}\quad \sum_g b_{m_g}=R\ },\qquad b_m=\log_2K_m .
\]

其中，固定分割点 \(\ell\)，令 \(h_\ell\) 为冻结的 ViT tail、\(F(X)\) 为未量化特征、
\(\widehat F_{U,\Theta,\mathbf m}(X)\) 为重组并量化后的重构特征，则全文唯一的真实目标为
\[
D_{\mathrm{tail}}(U,\Theta,\mathbf m)
=
\mathbb E_X\left\|
h_\ell\!\left(\widehat F_{U,\Theta,\mathbf m}(X)\right)
-h_\ell(F(X))
\right\|_2^2 .
\]
所有代理、初始化损失与诊断量都不能替代这一目标；正式接受、checkpoint 与验收均使用硬量化下的
\(D_{\mathrm{tail}}\)。

学习对象 = \(U\) + 多模式码本 \(\Theta\) + 组级模式 \(\mathbf m\)。**本阶段不学习 prior。**

**阶段一要提供严格统计证据的三个经验命题**：
1. 固定 \(U,\Theta\) 时，存在显著优于均匀分配的非均匀分配；
2. 学习算法能找到该非均匀分配的**大部分**收益（阈值见 S1-s；
   达不到则本命题降为「找到了**显著的**非均匀收益」）；
3. 联合学习 \(U+\Theta+\mathbf m\) 优于分别缺少 \(U\) 学习、缺少码本联合更新或缺少非均匀分配的模型。
   S3 因此必须包含「\(\Theta\) 冻结 + \(U\) 学习 + 非均匀分配」对照；否则只能验证
   \(U\) 与分配两个因素，不能严格支撑“\(U\)、码本、非均匀分配联合优化”的完整声称。

**理论与实验的边界**：固定 \(U,\Theta\) 后，可行集合
\(\mathcal A_R=\{\mathbf m:\sum_g b_{m_g}=R\}\) 有限，因此真实最优分配
\(\mathbf m^\star\in\arg\min_{\mathbf m\in\mathcal A_R}D_{\mathrm{tail}}(U,\Theta,\mathbf m)\)
必然存在；理论本身不保证它非均匀，也不保证 S2 找到完整 32 组的全局最优。
S1 在可穷举子格中检验“非均匀严格更优”，S2/S3 检验算法在同预算下达到的可行解。
\(\widehat\Phi_J\) 与 \(\Phi_{\rm sep}\) 仅用于提出候选，不能被当作真实最优性的证明。

**明确后置到阶段二**：真实熵率 \(R_\psi\)、prior/log-prior、ECVQ 联合指派、rANS、
token 条件熵、正式 BD-rate、以及**「在匹配真实码率下超过 ORFC」**这一声称。

主线依据：`节点记录/统一主线确立_失真分解到条件熵_20260730.md` §1.1–1.3。

## 〇、三个量必须分开，且 Jacobian 项是**测量量**

| 记号 | 定义 | 与 \(D\) 的关系 | 怎么得到 |
|---|---|---|---|
| \(\widehat\Phi_J(\mathbf m)\) | 主线 §1.1 二次自项 \(\mathbb E\sum_g\|J_h\delta_g(m_g)\|^2\) 的**估计** | \(D=\widehat\Phi_J+\widehat C+\widehat N\)（**构造闭合**） | JVP 测量，见 §0.1 |
| \(\Phi_{\rm sep}(\mathbf m)=\alpha+\sum_g\phi_{g,m_g}\) | 从完整 \(D\) **拟合**的 operational 可分代理 | \(D-\Phi_{\rm sep}\ \neq\ \widehat C+\widehat N\) | `build_selffit_design.py` 最小二乘 |
| \(D(\mathbf m)\) | 完整 tail 失真 | — | 直接测量，唯一被优化的量 |

**三条强制纪律**：
1. \(\widehat C+\widehat N\) **只解释 \(\widehat\Phi_J\to D\)**，不解释 \(\Phi_{\rm sep}\to D\)；
2. \(\mathrm{Regret}\)、\(\rho_{\rm rank}\)、\(\Omega_{\rm near}\) 一律带下标 \(J\) / `sep`。
   此前所有 \(\hat\Omega\)、H1 7.79×、T3 稳定性、四个水位证书、自拟合/迁移增益
   **全部属 sep 分支**，不得当作 \(\widehat\Phi_J\) 的证据；
3. S1 同时冻结 \(\mathbf m_J\) 与 \(\mathbf m_{\rm sep}\)；S2 两个 DP 各自产生提案，由完整 \(D\) 仲裁。

### 0.1 \(\widehat\Phi_J\) 的测量精度（**执行前必做**）

\(\Phi_J\) 的**代数定义**严格，但实现是 JVP/有限差分，未必精确——
既有实验出现过约 **4%** 的 JVP 误差。因此：

- **先确认 `decompose_output_vectors` 的 `group_response` 产生方式**（有限差分 vs autograd JVP；
  `p1_fixed_rate.py:estimate_c` 用的是 `--eps 0.01` 中心差分）；
- 做**步长收敛检验**（\(\epsilon\) 扫描）与 **autograd-JVP 对照**，报告相对误差；
- 误差不可忽略时，全文一律写 \(\widehat\Phi_J,\widehat C,\widehat N\)，
  **不得称「精确 Jacobian 项」**；
- **关键**：`nonlinear = distortion − paired_quad` 是**残差定义**，
  所以 JVP 误差全部被吸收进 \(\widehat N\)，且 \(D=\widehat\Phi_J+\widehat C+\widehat N\)
  **恒成立**。该闭合只验证**计算一致性**，**不能验证局部线性近似的准确性**（I7）。

### 0.2 \(\widehat\Phi_J\) 表是逐项可加的，且极便宜

阶段一无 ECVQ 联合指派 ⇒ \(\delta_g\) 只依赖 \(m_g\)；\(J_h\) 在 \(F\) 处求值与 \(\mathbf m\) 无关
⇒ \(\Phi_J\) 对 \(\mathbf m\) **逐项精确可加**（非拟合、无设计矩阵、无 gauge 自由度）。
这里的 \(\delta_g\) 一律来自硬最近邻量化；soft 误差只用于内层梯度，不进入该表。
`group_response` 是 `[B,G,...]`，`response.square().sum(2)` 给出逐组分量 ⇒
**6 次均匀 run（3..8 bit）填满 \(32\times6\) 表**，DP 直接给出 \(\mathbf m_J\)。（可加性由 I11 实证。）

## 二、阶段边界（为什么本轮不能声称超过 ORFC）

| | `orfc/run_soft_pq.py`（ORFC v1 训练器） | `orfcv1/allocation_train.py`（本轮工作面） |
|---|---|---|
| 量化器 | 单个 `SoftPQ(G,K,d)` | `MultiModeSoftPQ`，6 档 (3..8 bit)，各档码本独立 |
| 率 | 可学 `log_prior` + ECVQ \(\lambda\) 偏置指派，`loss=R+λD`，rANS 实测 | **无率项**（`lmbda=0.0` ⇒ `log_prior` 未被创建）；率是硬约束 |
| \(U\) | `OrthogonalTransform`（skew）+ Adam | `DirectOrthogonalTransform` + `CayleySGD` |

⇒ 本轮内部对照必须是**同名义总比特的单模式定长均匀基线**（关掉 entropy prior / ECVQ、
统一用 Cayley）；**原始熵编码 ORFC 只作外部参考数字**；合并两套代码属阶段二。
`primary_only` 不是代码 flag，只是 `--remainder-grad-ratio 0` 的 run 名。

## 三、判据量

### 3.1 描述量（S0，带选择偏差，**不作判据**）

\(\mathrm{Regret}_\bullet=D(\mathbf m_\bullet)-\min_{\mathbf m\in\mathcal S}D(\mathbf m)\)，\(\bullet\in\{J,\rm sep\}\)；
\(\rho^\bullet_{\rm rank}\)；\(\Omega^\bullet_{\rm near}\)（\(\tau\) 取 top-1% 与 top-200）。
同一有限样本上取 \(\min_{\mathcal S}D\) 产生向上的选择偏差，但那只是**期望方向**，
**不是样本级也不是高概率上界**。必须写 \(\operatorname{range}_{\mathcal S}\)。

### 3.2 两个**分开的**恢复率（联合训练会改变整个分配失真面）

| | 问题 | 分母 | 分子 |
|---|---|---|---|
| **初始恢复率** | 固定**初始** \(U_0,\Theta_0\) 时，分配搜索恢复了多少初始 oracle 收益 | \(G^{(0)}_{\rm oracle}\)（S1-b 穷举） | \(G^{(0)}_{\rm search}\)（**S1-s**，冻结模型的搜索） |
| **最终差距** | 联合训练后固定**最终** \(U^\ast,\Theta^\ast\)，在 **S2-8** 的子格上**重新枚举**，最终分配距最终 oracle 还有多远 | \(G^{(\ast)}_{\rm oracle}\) | \(G^{(\ast)}_{\rm learned}\) |

**硬纪律**：
- **不得用初始 oracle 评价最终模型**；
- **不得把 calibration 上的最优值直接当作测试结论**——候选由 cal 选定后即冻结，
  **比较与置信区间一律在 §4.0.1 的单次开封点、于 measure-3000 上完成**；
- 恢复率**仅当对应 \(G_{\rm oracle}\) 的 CI 严格大于零时才报告**（分母近零时比值 CI 发散）；
- 始终优先报告绝对量 \(D_{\rm learned}-D_{\rm uniform}\)（主）与 \(D_{\rm learned}-D_{\rm oracle}\)（次）。

\(\gamma\)、\(\widehat N/D\)、signed/absolute \(\widehat C\)、span、Hamming 表**一律机制诊断，不设闸门**。

**温度缩放公式**（DIMQ：softmin gap \(\le\tau\log K\)）——逐**模式**而非全局：

\[
\boxed{\ \tau_m(t)=\tau_0(t)\cdot\frac{b_{\rm ref}}{b_m}\ },\qquad b_m=\log_2K_m,\ b_{\rm ref}=6 ,
\]

使各档的 softmin gap 上界齐平。\(\tau_0(t)\) 沿用现有退火曲线。
当前 `MultiModeSoftPQ.temperature` 的 setter 把一个全局 float 扇出到每个子量化器，**需改为逐档**。

**适用范围的诚实声明**：\(\tau\log K\) 只直接约束 **log-sum-exp softmin** 的间隙。
**执行前必须先确认 `SoftPQ` 的软化形式**：若它是**软质心加权**（softmax 权重对码字求和）
而非 log-sum-exp，则上式**只能作为启发式缩放**，
**不得声称「已均衡各档的完整失真松弛误差」**——那要由上文的 soft–hard 失真差审计实测。

### 4.1.1 **四个「二选一」全部冻结为唯一正式配置**

保留自由选择等于给结果留了四个事后可调的旋钮。**本轮直接取推荐组合，
不再预注册两个分支**；被放弃的一支只在阶段二作消融。

| 项 | **正式配置** | 被放弃的一支 |
|---|---|---|
| \(U_0\) | **OPQ warm-up**（仅用 train-core），规格见下 | identity（会让 learned-\(U\) 的增益混入「从零学正交变换」的红利） |
| 内层码字指派 | **soft relaxation**（`SoftPQ` 已实现） | STE（有偏代理梯度） |
| 未选模式维护 | **方案 A**：只更新对应码本，对 \(U\) 停止梯度 | 方案 B（带 \(\beta\) + 梯度占比审计） |
| 提案比例 | **固定 1:1:4:2**，三个搜索（S1-s / S2-8 / S2-32）**一律相同** | 按历史 cal 接受率自适应 |

**\(U_0\) 的 OPQ warm-up 规格**（先写后跑，全部消融格共用同一次运行的输出）：

| 项 | 值 |
|---|---|
| 数据 | **train-core 4,000**，blk20 特征，与正式训练同 cache / layer / norm |
| 码本大小 | 每组 \(K=64\)（\(=2^6\)，对应 \(b_{\rm ref}=6\) 的均匀档）；\(G=32,d=32\) |
| 迭代 | OPQ 交替 **30** 轮（每轮：固定 \(U\) 更新 PQ 码本 → 固定码本由 Procrustes/SVD 更新 \(U\)） |
| 内层 K-means | 每轮 **10** 次 Lloyd 迭代，k-means++ 初始化 |
| seed | **0**（单次运行，输出即 \(U_0\)，不做多 seed 挑选——挑 \(U_0\) 就是用同一批数据选择模型） |
| 输出 | \(U_0\) 及其正交误差 \(\|U_0^\top U_0-I\|_F\)（记录，\(>10^{-5}\) 即停） |

**这次 warm-up 产生的 \(K=64\) 码本不得直接当作 6-bit 档的初始码本**——
六档一律按 §4.2 在 \(U_0\) 变换后的特征上**重新独立 K-means**，
否则 6-bit 档天生比其余五档成熟，与「不载入原 ORFC 6-bit 码本」是同一条禁令。

**内层损失（写死，S1-s / S2-8 / S2-32 / S3 全部内部格通用）**：

\[
\boxed{\ \mathcal L_{\rm inner}
=D_{\rm soft}\big(U,\Theta,\mathbf m_t\big)
+\beta\,\mathcal L_{\rm maint}\big(\operatorname{sg}(U),\Theta;\mathcal B_t\big)\ }
\]

- **只有当前已接受分配 \(\mathbf m_t\) 的完整（soft）tail 失真可以更新 \(U\)**；
- \(\mathcal B_t\) 是按预注册循环表取得的固定码率可行分配小批次，覆盖当前
  \(\mathbf m_t\) 未使用的组—模式；维护项定义为
  \[
  \mathcal L_{\rm maint}
  =
  \frac1{|\mathcal B_t|}
  \sum_{\widetilde{\mathbf m}\in\mathcal B_t}
  D_{\rm soft}\!\left(\operatorname{sg}(U),\Theta,
  \widetilde{\mathbf m}\right),
  \]
  并将梯度掩码到未选码本。这里正交变换在编码和逆变换中的**全部出现位置**都停止梯度，
  不能只 detach \(UF\) 后又让逆变换路径更新 \(U\)；
- 因此 **\(\nabla_U\mathcal L_{\rm maint}\equiv0\)**，维护项只用与主目标同口径的
  task-tail 失真更新候选码本，不再引入特征重构这一额外目标；
- **代码级断言**（I10）：在若干随机 step 上单独反传 \(\mathcal L_{\rm maint}\)，
  核 \(\|\nabla_U\mathcal L_{\rm maint}\|=0\)（不是「很小」）。**否则维护分配
  仍会通过辅助路径驱动 \(U\)**，把此前排除的目标冲突重新引入。

| **gauge 单调性的声称边界** | gauge 得到的单调性**只是固定码率约束下的一个等价参数表示**（\(\Phi\to\Phi+cR\) 是常数平移，决策不变），**不能**解读为「真实 RD 曲线单调」或「加比特一定降失真」。**真实菜单单调性只由 M3 给出**（它测的是完整 \(D\)，且有置信界与允许违规比例）。两处「单调」不得互相引用 |
| 求解 | 代理最优解一律由**精确 DP**（\(O(GMR)\)）求得，不依赖凸性、不依赖闭式水位；水位证书只在每实例可验时作为附加说明 |
| 完整失真 | **每轮必须在当前 \(U,\Theta\) 下以硬最近邻重算设计集的完整 \(D\)**，用 §4.2 一次性抽定并落盘的**固定 \(n_{\rm fit}=500\) 个 train-core basename**（图集跨轮不变，否则跨轮 \(\phi\) 差异同时含模型变化与样本变化，两者不可分离）。**沿用上一轮的 \(D\) 值 = 沿用过时代理**，与本节禁令等价 |

**查询预算必须分三栏报告**（代理维护也是算法获得的搜索信息，不能完全排除）：

\[
B_{\rm accept}=T_{\rm outer}\times 8=160,\qquad
B_{\rm proxy}=T_{\rm outer}\times\big(|\mathcal F_\bullet|+6\big),\qquad
B_{\rm total}=B_{\rm accept}+B_{\rm proxy}.
\]

即 **S2-8**：\(B_{\rm proxy}=20(64+6)=1{,}400\)，\(B_{\rm total}=1{,}560\)；
**S2-32**：\(B_{\rm proxy}=20(256+6)=5{,}240\)，\(B_{\rm total}=5{,}400\)。
「相同搜索预算」指 **\(B_{\rm accept}\)、\(B_{\rm proxy}\)、\(B_{\rm total}\) 三者逐格相同**；
只报 160 会系统性低估实际查询成本。

**历史 `decomposition_R*.npz` 的复用边界**：只有当 \(U\)、**全部六档码本**与分配表
与正式实验**完全相同**时才可复用。§4.2 规定了全新的统一初始化 ⇒
**E4 列出的既有 run 一律降为历史描述**，S1-c 的分解必须在冻结初始化下重算。
好消息是 `decompose_output_vectors` 的代码路径不变，重算是执行成本而非开发成本。

#### 作用域必须拆开：**S2-8** 与 **S2-32**

| | **S2-8** | **S2-32** |
|---|---|---|
| 搜索域 | 固定八组子格（24 组冻结在均匀档），6,147 点 | 完整 32 组 |
| 用途 | 算**初始恢复率**、**最终差距**、**最终 cal oracle** | **完整方法实验** |
| oracle | 可穷举 ⇒ 有 | \(R=128\) 下可行分配约 \(5.63\times10^{17}\) 点（精确 562,875,591,270,069,891）⇒ **不计算 oracle** |
| 报告 | 恢复率 + 绝对差 | **只报相同搜索预算下达到的最终 measure 失真** |

两者共享 §4.2 初始化、§4.1 预算、S2-P 刷新、S2-U 维护策略。
**S2-8 先跑**（它同时给出 §3.2 的两个恢复率）；S2-32 是主结果。

#### 外层 / 内层

- **提案来源**：\(\widehat\Phi_J\)-DP、\(\Phi_{\rm sep}\)-DP、真实失真相邻交换、trust-region
  （数量与预算见 §4.1）；
- **接受测试**：只有 **cal-500 上完整 \(D_{\rm tail}\) 下降**才接受
  （两个 DP 最小化的都是代理，不保证完整目标下降）；
- **内层**：固定当前**硬分配**，联合更新 \(U\) 与全部六档码本；
- **checkpoint**：只按 **dev-500** 的完整 tail 失真选择，不用训练损失。

**提案比例：三个搜索统一用预注册固定比例，Regret 一律不参与决策**

\[
\boxed{\ \widehat\Phi_J\text{-DP}\ :\ \Phi_{\rm sep}\text{-DP}\ :\ \text{exchange}\ :\ \text{trust}
\ =\ 1:1:4:2\ }
\]

**S1-s、S2-8、S2-32 全部用这一个比例**，不随轮次、不随作用域改变。
此前写的「S2-8 可用真实 Regret 调整提案比重」**作废**，两条理由都是硬的：

1. **子格 oracle 只对应 \(U_0,\Theta_0\)**。内层每更新一次，失真面与 oracle 都改变；
   除非**每轮重新穷举 6,147 点**（那会把 \(B_{\rm proxy}\) 抬高两个量级），
   当前轮的真实 Regret **根本不知道**。用初始 oracle 算的 Regret 去指导第 \(t\) 轮
   等于用过时信息，与 S2-P 的禁令同类；
2. **更要命的是信息泄漏**：oracle 就是 \(\mathbf m_D^{\rm cal}\)，
   用它的 Regret 挑提案族 = 把答案透给搜索算法，
   会使 **S1-s 的初始恢复率系统性偏乐观**——而恢复率正是命题 2 的判据。

\(\mathrm{Regret}_J\)、\(\mathrm{Regret}_{\rm sep}\) **仅作事后诊断**
（「哪个代理更接近 oracle」是一个描述性问题），
**不得**进入 S1-s / S2-8 / S2-32 的任何调度、提案、接受或停止决策（I16）。

#### 离散量的处理（**不再声称「穿过硬 argmin 求梯度」**）

硬最近邻指派不可直接微分，此前的 DOPQ 式表述不严谨。分三层写死：

| 层 | 规定 |
|---|---|
| **外层模式 \(\mathbf m\)** | **纯离散搜索，不求任何梯度**。提案来自两个 DP + 邻域交换 + trust-region，接受由 cal 完整 \(D\) 判定 |
| **内层码字指派** | **soft relaxation（已冻结，§4.1.1）**。`SoftPQ` 已实现；STE 分支放弃（有偏代理梯度） |
| **cal / dev / measure** | **一律硬最近邻**。任何验收数字都不来自 soft 前向 |

**新增审计**：逐模式的 **soft–hard 失真差** \(D_{\rm soft}^{(m)}-D_{\rm hard}^{(m)}\)，
逐轮记录。该差随退火应收缩；若某档长期偏大，说明该档的松弛偏置在污染提案比较。

#### S2-U：未选模式既不能失配，**也不能反过来驱动 \(U\)**

只更新选中档位 ⇒ \(U\) 漂移后未选码本与新表示失配 ⇒ 下一轮外层比较时这些模式
因「长期没训练」而显得很差 ⇒ **路径依赖**，算法学到的是「最常训练的模式」。
但若维护用的候选分配 task-tail 损失**同时更新 \(U\)**，\(U\) 又会被**未接受分配**驱动，
与「最小化当前分配的完整 tail 失真」冲突。

**已冻结为方案 A（§4.1.1），必须明写在 run 配置里**：
未选模式维护损失**只更新对应码本，对 \(U\) 停止梯度**——
即 §4.1.1 的 \(\mathcal L_{\rm inner}\) 中维护项对正交变换的全部使用均经
\(\operatorname{sg}(U)\)，
故 \(\nabla_U\mathcal L_{\rm maint}\equiv0\)（**恒等于零，不是「很小」**，由 I10 代码级核验）。
带权重 \(\beta\) + 梯度占比审计的方案 B **已放弃**——它只能**监测**\(U\) 被辅助路径污染的程度，
不能**排除**污染，而排除是这一节的目的。
（\(\beta\) 仍出现在 \(\mathcal L_{\rm inner}\) 里，但它只调节维护项对**码本**的强度。）

维护分配只按启动前冻结的循环表产生；它们只执行上述码本维护梯度。
只有外层已接受的当前分配 \(\mathbf m_t\) 能通过主损失更新 \(U\)。

**审计量（每轮记录）**：每个 \((g,m)\) 的**有效更新次数**（判据是
**每个可行模式 ≥ \(n_{\rm min}\) 次有效更新**，不是「非零更新」）；梯度范数；
训练前后菜单单调性（复用 M3 协议）；未选模式相对当前 \(U\) 的重构误差。

#### 实现约束

- 独立多模式码本先保留（前缀嵌套不保证换档连续——新增质心使最近邻指派离散跳变；
  残差/层次式嵌套作为阶段二消融）。前提是 M3 已通过；
- **正交参数化与优化器统一为 `DirectOrthogonalTransform` + `CayleySGD`**，
  用于**全部内部消融格**（含单模式定长均匀基线）。原 ORFC 的 skew + Adam
  **只作外部参考数字**，不进入任何内部对照。（v4/v5 早前写的「保持 ORFC 原有参数化」
  与 §二 表格自相矛盾——原 ORFC 是 skew+Adam，本工作面是 Cayley——此处按前者作废、
  统一取 Cayley。）**本轮不引入 Householder**，参数化选型属阶段二消融；
- 温度按 §4.1 的 \(\tau_m(t)=\tau_0(t)b_{\rm ref}/b_m\) 逐档缩放；
- **不引入** `lmbda>0`、`log_prior`、ECVQ 偏置指派、rANS（全部阶段二）。

### S3：三个因素的联合优化消融

| | 均匀分配 | 非均匀分配 |
|---|---|---|
| **冻结共同初始化的 \(U\)** | fixed-\(U\) uniform | fixed-\(U\) allocation |
| **学习 \(U\)** | learned-\(U\) uniform | **full joint** |

为单独检验码本学习的贡献，增加第五个内部对照：

\[
\boxed{\ \text{learned-}U+\text{frozen-}\Theta+\text{nonuniform allocation}\ }
\]

该格从同一 \((U_0,\Theta_0)\) 出发，学习 \(U\) 与分配、冻结已经完成统一预训练的六档码本。
因此 full joint 与它的差异只来自正式联合训练过程中是否允许继续更新 \(\Theta\)；
该比较检验的是**码本联合适配**的增益，不是“是否需要任何码本学习”。

五个内部格按**相同规则**训练（**同 §4.2 初始化 checkpoint**、同 step 数、同优化器
（Cayley）、同 checkpoint 规则、同 S2-U 策略、**同三栏搜索预算 \(B_{\rm accept}/B_{\rm proxy}/B_{\rm total}\)**、**同 seed**）。
frozen-\(\Theta\) 格仍执行相同的维护前向与查询日程，但屏蔽全部码本梯度；这是该消融唯一额外关闭的更新路径。
另设一个辅助基线：**单模式定长均匀基线**（单个 `SoftPQ`、关闭 entropy prior / ECVQ、
相同名义总比特）。**不称它为「定长 ORFC」**——它用 Cayley 而非 skew+Adam，
不是原 ORFC 的复现；**原始熵编码 ORFC 只作外部参考数字**。

**主功效终点中的 uniform 就是这一格**：

\[
\boxed{\ \Delta_{\rm main}
=D_{\rm measure}(\text{full joint})-D_{\rm measure}(\text{learned-}U\ \text{uniform})\ }
\]

两者必须共享初始化 checkpoint、训练步数、优化器、码本维护策略与 seed——
唯一差别是分配是否非均匀。**fixed-\(U\) uniform 与单模式定长均匀基线是辅助对照**，
不承担主功效终点。

**P8（两个可计算版本）**。原方向（\(\gamma\) 增大且 \(|C|/D\) 减小）不成立：
\(\gamma\) 只描述固定 \(U\) 下的潜在收益，优秀的 \(U\) 可能同时降低所有 \(c_g\) 并降低异质性；
\(\widehat C\) 是**带符号量**，负值可能是有利抵消；E6 已表明降低 interaction 不自动降低完整失真。
且 \(\min_{\mathbf m}D(U,\mathbf m)\) 在完整 32 组上不可计算。改为：

- **八组子格（S2-8）**：在 cal-500 上分别穷举 \(U_{\rm learned}\) 与 \(U_{\rm fixed}\) 的子格，
  **各自冻结其 cal 经验最小点**，再在 **§4.0.1 的单次开封点**、于 measure-3000 上
  比较这两个冻结候选。**不得直接比较两个 cal 最小值**（各自都被同一批数据选择过，
  双侧 winner's curse）；报告的是 measure 上的配对差与 CI；
- **完整 32 组（S2-32）**：**三栏搜索预算相同（\(B_{\rm accept}/B_{\rm proxy}/B_{\rm total}\)）
  下最终达到的 measure 失真差**，不出现 \(\min_{\mathbf m}\)，不出现 oracle。

\(\gamma\)、signed \(\widehat C\)、\(|\widehat C|\)、\(\widehat N\)、分配变化量全部机制诊断，**不设方向性闸门**。

### S4：四点**名义码率**曲线（本阶段不做正式 BD-rate）

- 四个码率点的全部模型、分配、checkpoint 与下游评估配置必须在 measure 开封前完成并冻结；
  开封后只允许前向评估，不能根据 R=128 的结果再训练或选择其余码率点；
- 报告 \(R\in\{128,160,192,224\}\) 的「名义码率—失真 / 任务性能」曲线；
- **不得**称为与 ORFC 的实际 BD-rate 比较；
- 图数按指标分别功效分析：tail 失真用 **3,000 图**；分类/分割按**逐图 correctness / IoU**
  分别分析，尽量用完整验证集（现状分类 500 / 分割 100 明显不足）；
- **5 个预注册 seed**（§4.1）+ 图像层 × seed 层**分层 bootstrap**，
  同时逐 seed 报告差值与方向；
- 复用 `eval_v1_1_all.py`（`--allocation_npz/--allocation_index/--modes`）。

### **阶段一通过条件（先写后跑）**

**全部条件在 §4.0.1 的单次开封点、按下列顺序评估。**

**主功效终点（gatekeeping，开封后第一个测的量）**：measure-3000 上 **R=128** 的
\(\Delta_{\rm main}=D(\text{full joint})-D(\text{learned-}U\ \text{uniform})\)
显著为负，两格共享 §4.2 初始化、步数、优化器、维护策略与 seed。

**显著性算法**：**按图像层 × seed 层分层**——每个 seed 各自在 3,000 图上配对，
先在 seed 内做图像层配对统计，再跨 seed 合并（分层 bootstrap，seed 作为第二个重抽层）。
**不得把 \(3{,}000\times S\) 个观测当独立样本**，那会把 seed 间方差算没。
正式协议固定 \(S=5\)。判据为分层 bootstrap 得到的单侧 99.7% 上置信界小于零；
同时报告五个 seed 的逐 seed 配对差。该项不过 ⇒ 后续全部只作描述。

其后（顺序即 §4.0.1 第 2–5 步）：
1. **命题 1**——确认性比较只包括主集与随机集各自的
   \(\mathbf m_D^{\rm cal}\) 对 uniform；先检验主集，再检验随机集。
   \(\mathbf m_J,\mathbf m_{\rm sep}\) 只用于比较两个代理，列为支持性结果；
2. **主集与预注册随机八组集都通过**才可称「稳定获得非均匀收益」；仅主集通过
   ⇒ 只能称「存在一个有效子问题」。两套子格**同批冻结、同批开封**，
   随机集是否跑**不**取决于主集在 measure 上的显著性（§4.0.1）。
   这里的“稳定”对命题 1 只表示“在同一冻结初始化下的两个预注册子格中复现”；
   五个训练 seed 检验的是 full-joint 方法的稳定性。二者均不外推为任意八组子格
   或全部 ViT 层均成立；
3. **命题 2**——初始恢复率的下置信界 > 50%（否则降级表述，见 S1-s）；
4. **命题 3**——full joint 分别优于：
   fixed-\(U\) allocation、learned-\(U\) uniform、以及
   learned-\(U\)+frozen-\(\Theta\)+nonuniform allocation。
   主终点已完成第二项；对剩余两项使用 Holm 校正的配对单侧检验。
   三项共同支持 \(U\)、\(\Theta\) 与非均匀分配的联合优化；其中 frozen-\(\Theta\)
   对照支持的是码本在正式阶段的联合适配。任何一项不通过都只报告
   “full joint 达到最低观测失真”，不声称相应因素具有独立增益；
5. **下游非劣**——不是 \(p>0.05\)。**下游主指标 = 分类 top-1（R=128）**，
   分割 mIoU 为次指标。所有
   \(\Delta\mathrm{Acc}\)、\(\Delta\mathrm{mIoU}\) 均定义为
   **full joint − 同码率 learned-\(U\) uniform**，与主功效终点使用同一对照；
   预先给出非劣界并检查**单侧置信区间**：
   \[
   \Delta\mathrm{Acc}>-\epsilon_{\rm cls},\qquad \Delta\mathrm{mIoU}>-\epsilon_{\rm seg} .
   \]
   **多重比较规则（两层，不是一次 8 项校正）**：
   **第一层**——\(R=128\) 的分类 top-1 是**唯一主指标**，**单独检验、不校正**；
   **第二层**——该项通过后，对其余 **7 项**（分割 \(\times4\) + 分类 \(\times3\)）
   做 **Holm 校正**，全部为支持性证据。主指标不过 ⇒ 第二层只作描述。
   「证据不足」不等于「非劣」。

**端到端跑法**：
1. **先建 §4.2 统一初始化 checkpoint**（§4.1.1 规格的 OPQ warm-up 得 \(U_0\) →
   六档独立 K-means → \(U_0\) 冻结下的六档均衡预训练，按 dev-500 判停），
   同时抽定并落盘 \(n_{\rm fit}=500\) 的 \(\Phi_{\rm sep}\) 拟合图集，核 I14、I20。
   **这一步在任何测量之前**；
2. 冻结后在 cal-500 上跑 **一次** S0-M 菜单审计（M2 最近邻分位、M3 两级容差 + Holm）；
   不过则本次正式协议停止；任何修改必须进入新的计划版本与预注册 run；
3. S0-F2 JVP 精度检验 → 决定记号；S0-F3 填表，核 I11（跨 run 版本 + 底噪容差）；
4. S0-F4/F5/F6 **在新初始化下重算 npz 后**读盘，描述量表 **\(J\) 与 sep 两栏分开列**；
   既有 run 只作历史对照；
5. S1-b 先用 **n=8 图、只放开 3 组（~10 点）** smoke run，核 I1、I3、I4、I6、I7、I17、I19；
6. 通过后上主集 + 随机集，各 6,147 点 × cal-500，nohup 后台，分片写盘；
7. **S1-s**（冻结 \(U_0,\Theta_0\)、固定 1:1:4:2、cal 上搜索）→ 冻结 \(\mathbf m_{\rm search}^{(0)}\)；
8. S2-8 → 重算最终子格 oracle → S2-32 → S3 五个内部格；
   再完成并冻结 S4 四个码率点的全部模型与候选；每轮核 I9、I10、I12、I15、I16、I18；
9. **冻结全部候选/代码/超参/checkpoint 并落盘**，核 I19、I20 → **开封 measure-3000**，
   按 §4.0.1 的六步顺序评估，评估期间不回改任何配置；
10. 每阶段结果写入 `节点记录/` 新文件，append-only，**判据先写后跑**。

\(\gamma\)、\(\widehat N/D\)、signed/absolute \(\widehat C\)、\(\mathrm{Regret}_J\)、
