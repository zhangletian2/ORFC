## 1. 缺陷一：A2 的 16 个外层事件**全部接受 0 次交换**

两个锚点各 8 个事件，无一接受。因此 A2 的最终分配就是均匀分配，
**A2 与 A1 是同一个实验**：

```
R64   A2 末端 train D 507211.0     A1 末端 507214.0     相对差 6e-6（= fp32 噪声底量级）
R96   A2 末端        450398.4      A1 末端 450392.8     相对差 1e-5
```

主终点 `d = D(A2) − D(A1)` 在 holdout 上只会是噪声。花掉唯一的确认集去测一个
构造上为零的差，是这一轮里最不可挽回的错误，所以停在这里。

### 为什么一次都没接受：未选中模式的码本从未被训练

把 A2 训练后的码本与 v9 冻结起点逐元素比：

| | codebook_0 | codebook_1 | codebook_2 | U |
|---|---|---|---|---|
| R64 | **逐字节相同**（max\|d\| = 0.0） | 相对 Frobenius 漂移 **0.1223** | **逐字节相同** | 0.0861 |
| R96 | **逐字节相同** | **0.1488** | **逐字节相同** | 0.1110 |

均匀分配 `m = 1·𝟙` 下只有 mode 1 的量化器会被选中，
mode 0 与 mode 2 的码本梯度**恒等于零** —— 不是很小，是精确的零，
3096 步之后一个比特都没动。与此同时 `U` 转了 8.6% / 11.1%，mode 1 的码本动了 12–15%。

于是外层搜索的每一个候选，都是把某个组挪到一个**与已经旋转过的 U 完全不匹配的陈旧码本**上。
搜索不是没找到收益，是它被要求在一个被自己构造出来的坑里找：

```
R64  事件1 (step 344)   base 445698.5   最佳候选 g4→g15   448832.3   gain −3133  (−0.70%)
     事件8 (step 2752)  base 506865.8   最佳候选 g21→g1   512818.7   gain −5953  (−1.17%)
R96  事件1 (step 344)   base 343936.3   最佳候选 g3→g12   347623.7   gain −3687  (−1.07%)
```

对照 N10 Stage B：**同一个搜索器、同一个 cal-500、同一个均匀起点**，
在**未经训练**的冻结 codec 上，第一步增益是 **+1.65%**（R64）/ **+1.23%**（R96）。
符号翻转发生在 344 步联合训练之后，而这 344 步只训练了三个码本中的一个。

这条与 N10 的结论不冲突，也没有推翻它：Stage B 说的是「在 `(U₀,Θ₀)` 处非均匀收益存在且可被找到」，
本节点说的是「**当只有被占用模式的码本在训练时**，这个收益会被自己的训练过程抹掉」。
后者是 A2 的实现缺陷，不是关于非均匀分配的物理结论。

## 2. 缺陷二：训练在 ~350 步之后单调自毁，R96 三臂 G1 FAIL

`distortions.npy` 的轨迹（25 步滑动均值）：

```
step         25      100      200    ~350(min)     600      1k       2k       3k      end
R64      510007   455553   443782      430003    448955  467025   497737   506604   507273
R96      402349   350017   338378      325003    340112  355831   406333   447770   450508
```

两个锚点都在 **step 352 / 354** 触到最小值，随后单调恶化；
A3（11 362 步）继续恶化到 522 612 / 521 337。G1 结果：

```
R64  A1 +5.4093%  A2 +5.4099%  A3 +2.5279%   三臂 PASS
R96  A1 −5.7515%  A2 −5.7527%  A3 −22.4229%  三臂 FAIL —— 末端比冻结起点更差
```

**成因是 N11 §3 记录在案的那条边界警告的兑现。** `lr_theta = 1e+1` 是用
**200 步**探针选出来的，而正式训练是 **3096 步**，外推 15×。
200 步恰好落在这个瞬态的上升段：探针给 R64 的 442 459 与轨迹的 step-200 值 443 782 一致，
探针没有说谎，是**选择准则**问题 —— 在 200 步这个尺度上，最大的学习率总是赢，
argmin 因此必然跑到网格边界，而边界正是发散的方向。

值得注意：step-352 的最小值 **430 003 / 325 003 比探针的最好值还低**。
即这套 `(U, Θ)` 的联合训练**确实能带来 ~20% 的训练失真下降**，
它只是守不住 —— 缺的是衰减调度或早停，不是缺乏可学习性。

## 3. 已核实无误的部分（不必重做）

- W5 初始张量逐元素相同；W6 名义码率全程守恒；W7 `orth` 峰值 2.15–2.19e-05；
- 三臂的 `batch_indices.npy` 由同一 `(TRAIN_SEED, batch, count)` 生成，A1/A2 前 344 步同分配；
- 预算匹配按构造成立（`A3_over_A2 = 1.000`）；
- `holdout-500` 与 `measure-3000` 本节点均**未读取**。

## 4. 修复方向（属于 v11，需用户裁定后才动）

1. **码本陈旧**：每步对**全部三个模式**的码本取梯度（未选中模式在同一 batch 上按
   假设分配算辅助项），或在每次外层事件之前对未使用模式做一次 Lloyd 重拟合。
   相对 tail 前向，这个开销可以忽略。没有这一条，外层搜索在任何均匀起点上都必然接受 0 次。
2. **学习率选择准则**：探针长度必须与 `N_inner` 同量级，或引入衰减到 0 的调度并用
   **终点值**选参。step-352 的最小值说明衰减调度大概率能守住 −20%。
   全长 × 25 格不可行（≈230 min/锚点），可行的是先粗选 3–4 个候选再全长复评（≈80 min）。

在这两条落地之前，任何重跑都只会复现同一个空终点。
