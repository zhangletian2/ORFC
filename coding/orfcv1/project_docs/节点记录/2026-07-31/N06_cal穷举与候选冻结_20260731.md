## 0. 结论

1. 两个锚点各穷举 **993 个分配 × 500 图**（均匀点 + 全部 32×31=992 个有序一比特转移），
   各约 **5.2 / 5.3 min**，无任何代理预筛。
2. 冻结候选：**R64 = 从 g24 取一比特给 g7**；**R96 = 从 g15 取一比特给 g26**。
   两个都是唯一最小点（`ties_at_minimum = 1`），不需要动用字典序 tie-break。
3. 992 个候选中低于均匀点的：R64 **90 个（9.1%）**，R96 **103 个（10.4%）**。
   即绝大多数一比特转移是**有害**的——「非均匀更好」不是随便挪一比特就能得到的。
4. 跨进程重放核验通过：cal_sweep 进程复现 verify 进程的探针，相对偏差 1.77e-7 / 2.31e-7。
5. **cal 失真面 99.8% 可分**为「谁出这一比特」＋「谁收这一比特」两项之和（§3）。
   这是本节点唯一有理论价值的观察，但它是**描述量**，不进判据。

## 3. 描述量：cal 失真面几乎完全可加

把 992 个候选摆成 32×32（对角空缺）的 (donor, receiver) 矩阵，做二因素可加拟合
`D(i,j) ≈ rowmean_i + colmean_j − grandmean`：

| | R64 | R96 |
|---|---|---|
| 面的标准差 | 5,174.3 | 4,551.2 |
| 可加拟合残差 rms | **237.5** | **201.9** |
| 可加 R² | **0.998** | **0.998** |
| 最负交互项 | (24,15) −890.5 | (14,8) −1,583.5 |

**donor 边际**（该组出一比特、对全部收方取平均后相对均匀点的变化，负 = 有利）：

| | 最佳三个 donor | 最差三个 donor | 跨度 |
|---|---|---|---|
| R64 | g24 **−8,544**、g11 −3,097、g14 −809 | g7 +15,983、g23 +14,565、g19 +14,411 | 24,528 |
| R96 | g15 **−4,160**、g19 −453、g13 −10 | g14 +23,707、g16 +8,352、g22 +7,450 | 27,867 |

**receiver 边际**（该组收一比特、对全部出方取平均）：

| | 最佳三个 receiver | 最差三个 receiver | 跨度 |
|---|---|---|---|
| R64 | g7 +2,452、g27 +4,363、g16 +4,859 | g21 +11,249、g11 +8,789、g26 +8,201 | 8,798 |
| R96 | g26 +1,267、g19 +2,134、g27 +2,374 | g1 +8,033、g11 +5,334、g8 +5,076 | 6,766 |

三点值得记下来（**均为描述，无一进入判据**）：

1. **donor 跨度是 receiver 跨度的 2.8× / 4.1×**。组间异质性主要体现在
   「少一比特会掉多少」，而不是「多一比特能补多少」。
2. **receiver 边际全为正**：在 32 组里随便找一组给它多一比特，平均而言总失真反而上升——
   因为必须有人出这一比特。只有 donor 项足够负时净效应才为负，这正是
   前五名 donor 全同的原因。
3. **R96 的 g14 是极端的坏 donor（+23,707）**，单独一个组就把最差三名全占了；
   而 R64 的坏 donor 分布在 g7/g19/g23 上。两个锚点的组重要性排序不一致——
   同一网络、同一层、只换了均匀档 K，「哪些组重要」就变了。这与「非均匀分配必须在
   本锚点自己的 (U₀,Θ₀) 上重新求解」是一致的，不能跨码率照搬。

有意注明：`R² = 0.998` 的可加性**不是**「D 关于分配可分」的证据。
这里只枚举了均匀点的一比特邻域，donor/receiver 各只动一格；
可加性在这个薄邻域内成立是弱得多的命题，与 v8 时期 sep 分支的可分性讨论
（在整个 𝒜_R 上拟合）不是同一件事，**不得互相引用**。
