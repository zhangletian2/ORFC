# N24 V23--V25 高效联合优化验收（2026-08-06）

## 结论

V23 的候选码本适配消除了未选档位零更新，但完整训练仍未超过 V21；V24/V25 的确定性 active-set soft-min 也未通过短程门槛。当前主要偏差来自“多个分配共享参数并优化混合目标”，不再是 REINFORCE 方差、梯度缺失或严重码字坍缩。

## V23 完整训练

- 方法：当前分配正常联合更新；每步额外更新一个未选组--档位，候选梯度不进入正交变换。
- 100 epoch：2,028 s，246 image/s，峰值显存 2.20 GB。
- 候选组--档位最少获得 243 次更新；候选梯度进入正交变换的最大变化为 0；未选码本最小漂移 0.233。
- 最终分配只有初始化事件被接受，后续 62 次 DP 更新均未改变分配。
- 同一 val-500：V21 的 Tail MSE/J 为 296,848/163,616，V23 为 301,070/165,531；V23 的差值为 +4,221 MSE（95% CI [3,083, 5,370]）和 +1,915 J。因此不进入下游评测。

## V24/V25 短程

V24 用精确预算 DP 产生 3 个候选，在一次合并 Tail 前向中计算全部完整目标，并优化 soft-min；无 REINFORCE、leave-one-out、公平项或策略熵。

- V24（差值标准误温度）：第 1 步最大候选权重 92.4%，末期 99.97%；val-500 的 J 比固定分配短程基线高 480（95% CI [132, 828]）。
- V25（候选范围校准温度）：保证 active 候选持续获得非忽略权重，但最终报告集 MSE 322,123，与 V24 的 322,015 基本相同，仍差于 V23 候选适配的 319,093。
- 两者 hard parity、正交约束、候选 exposure、梯度覆盖均通过；dead centroid 比例不超过 0.8%。

## Exit 与下一步

停止“共享参数上的 active-set 混合损失”路线。下一步使用 allocation-conditioned 少步内层适配：所有精确预算候选从同一当前参数出发，分别执行相同次数的 `U + 所选码本` 更新，再在独立选择集上比较并保留胜者。该方法直接近似有限步的

\[
\min_{\mathbf m}\min_{U,\Theta_{\mathbf m}}J(\mathbf m,U,\Theta_{\mathbf m}),
\]

并明确报告候选数、内层步数与额外计算量；仍不声称得到全局 oracle。
