# N25 V26 条件内层适配与本轮收束（2026-08-06）

## V26 方法与验收

V26 用精确预算 DP 生成 3 个候选。每个候选从同一当前 codec 快照出发，分别执行 4 个 `U + 所选码本 + prior` 内层更新；独立选择集决定胜者，报告集只做诊断，胜者参数与分配一起写回。该过程不使用 REINFORCE、公平项、策略熵或多分配混合梯度。

- smoke：全部候选名义码率严格为 64 bit；选择集和报告集收益同向；hard parity、正交约束与参数写回通过，峰值显存 0.50 GB。
- 1,000 步：83.1 s，385 image/s，峰值显存 2.13 GB；两个接受事件的选择集/报告集收益均同向。
- 最终 val-500：V23 候选适配的 MSE/J 为 318,206/174,125，V26 为 319,430/174,893；V26 的 J 高 768，95% CI [202, 1,308]。短程门槛失败，不进入完整训练和下游评测。

## 本轮方法边界

1. VAQ 的方差代价与精确分配、RaBitQ 的结构化旋转与解析码本，都建立在比完整 ViT Tail 更强的结构假设上；二者不提供任意 Tail 下的联合 oracle。
2. V22 的固定代理 DP 快 6.45 倍，但候选码本陈旧且完整训练弱于 V21。
3. V23 消除了未选档位零更新，完整训练仍弱于 V21，说明码本陈旧不是唯一瓶颈。
4. V24/V25 的全信息 soft-min 避免采样方差，但优化的是共享参数上的平滑混合目标，短程反而变差。
5. V26 更接近“候选分别适配后比较”，但有限步排序不能预测后续训练轨迹，仍存在权重共享/短视排序偏差。

因此，本轮不能声称得到更接近独立重训 oracle 的新优化器。现阶段最强经验结果仍是 V21 的 REINFORCE + 严格覆盖训练；其有效性是经验结论，不是 oracle 最优性证明。

## 后续限定方向

停止继续调 REINFORCE 样本数、leave-one-out、公平权重、soft-min 温度或 lookahead 步数。下一阶段先改变问题结构：采用嵌套/层次化多码率码本，使不同档位共享可解释的父码字与增量码字，再用任务感知边际代价和精确预算 DP 选择分配。该方向通过结构共享减少“每个分配需要独立码本”的根本偏差；应先验证嵌套约束本身是否损害同档位 Tail MSE，再决定是否继续联合优化。
