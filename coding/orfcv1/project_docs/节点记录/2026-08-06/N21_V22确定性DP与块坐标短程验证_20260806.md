# N21：V22 确定性 DP 与块坐标短程验证

日期：2026-08-06

## 目的

用“任务代价表、精确预算 DP、完整目标验收、固定分配更新正交表示与码本”替代 V21 的 REINFORCE、leave-one-out、策略熵和 strict-fair 损失。分配步对当前参数是确定性的，只有完整 hard tail ECVQ 目标下降的候选才被接受。

## S0：冻结 checkpoint 的分配探针

`blk20/R64`，使用 64/64/128 张互不重叠的 calibration/selection/report 图像，top-8 DP，并用 32 个随机精确预算分配审计可分代理。

### V21 初始化点

- 随机分配的代理–完整目标 Pearson 相关为 0.949；
- 配对排序一致率为 0.895；
- DP 候选在独立 report 集上使 Tail MSE 从 716,772 降至 672,119，改善 44,653（6.23%）；
- 包含真实 ECVQ 码率的完整目标改善 22,293。

### V21 训练完成点

- Pearson 相关为 0.964，配对排序一致率为 0.938；
- DP + 完整目标重评保留当前分配，与 V21 冻结 codec 的全邻域局部稳定结论一致。

结论：局部可分代价在当前问题上具有较强排序能力；DP 对代理精确求解，top-K 完整目标重评阻止代理失配直接恶化真实目标。

## S1：500 步匹配短程实验

两臂均从 V21 同一 ORFC-Adam 初始 codec 出发：

| 方案 | 外层分配 | 初始 Tail MSE | 最终 Tail MSE | 最终 ECVQ 目标 |
|---|---|---:|---:|---:|
| DP-once | 起点求解一次 | 716,772 | 330,638 | 180,238 |
| DP-periodic | 起点 + 第 250 步刷新 | 716,772 | **328,429** | **179,185** |

DP-periodic 在第 250 步接受了新的非均匀分配，selection 集完整目标改善 255。最终 Tail MSE 比 DP-once 低 0.67%。

完整审计：

- 名义码率严格为 64 bit；
- hard-parity 相对误差约 `1.9e-7`，低于 `9.54e-7` 阈值；
- 正交误差增量约 `2.0e-5`；
- DP-once 所有激活组–档位均获得 500 步梯度；periodic 切换后最少获得 250 步；
- 激活码本最小参数漂移大于 0.062；
- 最终仅 8-bit 档出现 1/256 dead centroid（0.39%），没有严重码字坍缩；
- 训练吞吐为 394–443 images/s，峰值显存 2.13 GiB；
- 不存在策略概率过早收敛，因为 V22 已取消训练式概率分配。

## 实现订正

smoke 后发现 DP top-K 可包含当前分配，原审计会把浮点误差记为一次“接受”。正式短程前已：

1. 去重当前分配与重复 DP 候选；
2. 固定 NumPy/PyTorch/CUDA 种子；
3. 先保存 codec、allocation 和 `training_complete.json`，再执行 centroid 审计；
4. 每次分配更新额外在独立 report 集记录新旧分配差，report 不参与选择。

远端源码冻结于 `dev` commit `a525a87`。

## 当前决策

S0/S1 通过，进入 `blk20/R64` 100 epoch DP-periodic 完整训练。若同图 Tail MSE 优于 V21 和原始 ORFC，再冻结 checkpoint 执行 ImageNet 分类和 VOC 分割；若失败，优先检查周期更新时未激活码本的陈旧性，不回到 REINFORCE 调参。
