# N20：无需逐分配重训的高效联合优化文献调研

日期：2026-08-06

## 研究问题

理想目标为

\[
D_{\rm oracle}^\star
=
\min_{\mathbf m\in\mathcal A_R}
\min_{U,\Theta_{\mathbf m}}
D(\mathbf m,U,\Theta_{\mathbf m}),
\]

其中 \(\mathbf m\) 是满足固定总码率的组级档位分配，\(U\) 是正交表示，\(\Theta_{\mathbf m}\) 是该分配使用的码本。逐分配独立训练可定义 oracle，但无法在指数规模的 \(\mathcal A_R\) 上执行。

当前方法以策略分布、共享表示和多档码本近似该目标：

\[
\mathcal L
=
\mathbb E_{\mathbf m\sim\pi_\phi}D(\mathbf m,U,\Theta)
+\alpha\mathbb E_{\mathbf m\sim q_{\rm fair}}D(\mathbf m,U,\Theta)
-\beta H(\pi_\phi).
\]

REINFORCE 少量采样主要增加梯度方差；正确的 leave-one-out baseline 不改变期望目标。公平覆盖项和非零熵正则会改变目标，使 \(U\) 与码本持续服务于多种分配。若 \(\alpha=\beta=0\)，策略允许退化为单点分布，且能够全局优化，则分布目标在函数值上可以包含 oracle；现实缺口来自非凸协同训练、候选档位成熟度不一致和高方差，而非策略表示能力本身。

## 两篇核心论文

### VAQ：方差代理与精确整数分配

Paparrizos 等，*Fast Adaptive Similarity Search through Variance-Aware Quantization*，ICDE 2022。

- 先用 PCA 与特征值方差确定子空间重要性；
- 通过 MILP 在精确预算、档位上下界和比例约束下确定每组 bit；
- 分配确定后，分别训练 \(2^{b_g}\) 个中心的 K-means 码本；
- 分配求解是确定且快速的，但只对方差代理精确；没有联合学习 \(U\)、码本和分配，也没有 ViT tail 任务失真保证。

直接启发：只要建立组–档位任务代价表，固定预算分配可由多选背包 DP 精确求解，无需策略采样。

### RaBitQ：通过量化器结构消除优化变量

Gao 和 Long，*RaBitQ: Quantizing High-Dimensional Vectors with a Theoretical Error Bound for Approximate Nearest Neighbor Search*，SIGMOD 2024。

- 固定随机正交旋转，不学习任务相关 \(U\)；
- 使用隐式超立方体码本，最近码字可由逐坐标符号闭式计算；
- 对欧氏内积/距离建立无偏估计与高概率误差界；
- 没有组级非均匀分配，也没有 ViT tail MSE 的保证。

直接启发：通过结构化多档量化器降低不同档位独立训练的成本和不可比性；学习任务相关 \(U\) 后不能继续直接使用 RaBitQ 的随机旋转理论界。

## 暂定改造方向

采用“任务感知代价表、精确预算 DP、完整目标验收、同目标块坐标更新”。在当前分配 \(\mathbf m_t\) 与参数 \(Z_t=(U_t,\Theta_t)\) 下，测量单组档位替换的硬 tail 代价：

\[
\Delta_{gk}^{(t)}
=
\mathbb E_X\!\left[
D(\mathbf m_t^{g\leftarrow k},Z_t)-D(\mathbf m_t,Z_t)
\right].
\]

建立局部可分模型

\[
\widehat D_t(\mathbf m)
=
D(\mathbf m_t,Z_t)
+\sum_g\Delta_{g,m_g}^{(t)},
\]

并用 DP 精确求

\[
\widetilde{\mathbf m}_t
=
\arg\min_{\mathbf m\in\mathcal A_R}\widehat D_t(\mathbf m).
\]

DP 同时输出 top-\(K\) 分配；使用完整硬 tail MSE 重评 top-\(K\) 与当前分配，只接受真实失真下降的分配。随后固定分配，以同一个完整失真目标更新 \(U\) 和被激活码本，再周期性刷新代价表。

这一路线把分配块从高方差策略梯度改为确定性离散求解。若

\[
\sup_{\mathbf m\in\mathcal A_R}
|D(\mathbf m,Z_t)-\widehat D_t(\mathbf m)|\le\varepsilon_t,
\]

则 DP 解在固定参数下满足

\[
D(\widetilde{\mathbf m}_t,Z_t)
\le
\min_{\mathbf m\in\mathcal A_R}D(\mathbf m,Z_t)+2\varepsilon_t.
\]

完整目标验收与连续参数下降共同保证校准目标不升，但只能得到坐标意义的局部稳定解，不能无条件等同于逐分配独立训练的全局 oracle。

## 实施前必须验证

1. 单组代价模型在随机精确预算分配及全邻域交换上能否正确排序完整 hard tail MSE；
2. DP top-\(K\) 是否覆盖真实低失真候选，代理误差是否小于候选间隔；
3. 若可分模型失配，失配是否可由少量活动组的二组 mixed difference 修正；
4. 相比 REINFORCE，一个外层周期的硬失真、梯度方差、运行时间和 GPU 利用率是否改善。

若单组模型不能排序且二组修正仍无效，则 VAQ/RaanA 式可分分配不适用于当前 tail；需要回到完整目标上的结构化离散优化，而不是继续调整策略梯度超参数。
