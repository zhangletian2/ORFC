# N26 V22--V26 冻结下游评测（2026-08-06）

## Checkpoint 状态

- V22、V23：100 epoch 完整训练 checkpoint。
- V24、V25、V26：1,000 步短程 checkpoint，仅用于诊断，不能与完整训练作最终方法比较。
- 五个 checkpoint 均具备 `codec.pt`、`allocation.npy`、`train.json`，并在相同 ImageNet-500/VOC-100 口径冻结评测。

## 判断

V23 相对 ORFC：分类提高 3.4 个百分点，mIoU 提高 1.17 个百分点，分割像素准确率提高 0.13 个百分点；它是 V22--V26 中唯一完成完整训练且在分类、分割两端同时超过 ORFC 的方法。

V23 相对 V21：分类低 0.4 个百分点，但 mIoU 高 1.42 个百分点、分割准确率高 0.94 个百分点。V23 的 Tail MSE 高于 V21，却有更好的分割结果，说明仅用 Tail MSE 相对 V21 作唯一退出门槛会错过任务收益。后续应把冻结分类与分割设为共同终点，Tail MSE 保留为训练诊断指标。

V24--V26 尚未完整训练，其短程下游数字只说明训练不足和目标差异，不能据此比较最终上限。V25 的短程 mIoU 较高但分类明显下降，不能作为方法胜出证据。
