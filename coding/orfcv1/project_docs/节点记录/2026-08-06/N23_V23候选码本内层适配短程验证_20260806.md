# N23：V23 候选码本内层适配短程验证

日期：2026-08-06

## 改造

V23 保留 V22 的精确预算 DP 和完整目标验收，将梯度路由拆分为：

- 当前主分配的完整 hard tail ECVQ 损失更新共享 (U)、已选码本和 prior；
- 每步确定性轮询一个未选组–档位，使用局部替换的完整 tail 损失，只将梯度写入该候选码本行与 prior 行；
- 候选损失中的 (U) 显式 stop-gradient，其他码本不接收梯度。

远端源码：`dev` commit `cc85206`。

## 1,000 步匹配对照

| 指标 | V22 无候选适配 | V23 候选适配 |
|---|---:|---:|
| report-128 Tail MSE | 320,739 | **319,093** |
| report-128 ECVQ 目标 | 175,320 | **174,543** |
| 训练时间 | **80.3 s** | 130.3 s |
| 吞吐 | **398.7 images/s** | 245.6 images/s |
| 峰值显存 | 2.13 GiB | 2.20 GiB |

V23 训练时间为 V22 的 1.62 倍，仍显著低于 V21 每步七路分配前向。

Tail MSE 在 319/500 张图上改善。V23 的码率上升 0.179 bit/token，但完整 ECVQ 目标仍显著下降。

## 训练信号审计

- 最终未选组–档位的候选梯度覆盖最小值为 12；
- 候选损失对 (U) 的梯度注入为 0；
- 未选码本最小参数漂移为 0.050，候选码本不再停留于初始化；
- hard-parity 相对误差 `1.96e-7`，正交误差增量 `1.98e-5`；
- 各档 dead-centroid 比例不高于 0.78%，没有严重码字坍缩。

第 250 步分配在 selection 集改善 467，在 report-128 上差 128，说明单次小样本分配判定仍有噪声。但最终 report-500 配对改善具有明确置信区间，因此不使用该单次事件调整阈值。

## 决策

短程门控通过，进入 `blk20/R64` 100 epoch 完整训练。完整训练只有在同一 val-500 上优于 V21，才执行 ImageNet-500 分类和 VOC-100 分割。
