- `test_nested.py`：组合码本大小及前缀梯度共享测试。

## 嵌套结构定义

给定递增档位 (b_0<b_1<\cdots<b_M)，残差阶段大小为

\[
2^{b_0},\;2^{b_1-b_0},\ldots,2^{b_M-b_{M-1}}.
\]

第 (m) 档码本是前 (m+1) 个阶段码字的笛卡尔和，因此码字数严格为 (2^{b_m})。高档位反向会更新其全部低档前缀，从而为低档共享前缀提供训练信号；高档专属残差阶段仍可能因高档采样概率过低而欠训练，因此容量门包含低/中/高档混合分配。

该结构属于加性码本约束，表达能力可能低于无约束的独立 (2^{b_m}) 质心；容量门专门测量这项代价。

## 第三道门的严格口径

当前实现属于双时间尺度的近似坐标法：

- 内层：一个精确预算硬分配、一次 Tail 前向，更新共享 (U) 与嵌套码本；
- 外层：共享权重筛选候选，保留一半候选后分别短适配，根据短适配验证失真选 winner；
- 只有短适配排序 Spearman 达到阈值时，才用 winner 的负对数概率更新精确预算策略；
- 训练结束后固定 MAP 分配，再联合微调 (U) 与码本。

该实现避免 REINFORCE 少量采样与长期公平加性损失，但尚未计算

\[
\nabla_\phi L_{\mathrm{val}}
\bigl(\phi,U^*(\phi),\Theta^*(\phi)\bigr)
\]

的严格超梯度。因此它应称为“短适配校准的双时间尺度坐标近似”，不能称为严格可微双层求解。

## 初审四项修正与 smoke（补充）

针对初审意见已完成以下修正：

1. 容量门加入全档位覆盖约束的精确预算 DP，生成离均匀分配改动最少、且单个分配同时含低/中/高档的非均匀分配，并用组循环置换构造三个覆盖臂；容量门现在同时检查均匀臂和三个混合臂。

3. successive halving 强制保留 incumbent，并对 incumbent 与候选执行同样短适配；外层更新必须同时满足排序阈值和
   \[
   D_{\rm val}(\text{winner})<D_{\rm val}(\text{incumbent}).
   \]
   策略更新后还要求 winner 真正成为 MAP；若未实现则回滚策略参数。
4. PQ 前向改为稀疏组--档位路径，只计算当前分配实际使用的组合码本，不再先计算全部档位与全部组的距离。
5. 排序门与双时间尺度门取消 `cal-64/select-64/report-128` 验证碎片，统一使用固定 `validation-select500`；训练侧代价表与短适配仍使用 `train_fit`。

## 父节点条件化层次残差树已实现

已停止全局加性嵌套结构，并将码本参数化替换为
\[
c^{(m)}_{\mathrm{child}}
=c^{(m-1)}_{\mathrm{parent}}
+r^{(m)}_{\mathrm{parent,child}}.
\]
R64各层节点数为 `2/4/8`、分支数为 `2/2/2`；R96各层节点数为
`4/8/16`、分支数为 `4/2/2`。每条边拥有父节点条件化残差，因此参数量与三套独立码本相同，同时高档路径仍向祖先节点传递梯度。

初始化采用平衡父子匹配，并直接令边残差等于子码字减父码字。由此，每一层组合码本都是对应独立码本的一个排列。结构测试确认初始化后的硬量化集合严格一致；端到端 smoke 中，R64/R96 四个分配臂的初始化 Tail MSE 相对差最大分别为
`1.78e-7` 与 `1.17e-7`。

两 epoch 路径 smoke 完成，无 OOM、梯度缺失或稀疏路径不一致：层次树相对独立码本的最终平均差为 R64 `-0.28%~-0.29%`、R96 `-0.22%~-0.24%`。smoke 因训练长度不足以满足正式收敛窗口，按合同为 `INCONCLUSIVE`，仅证明实现与精确初始化成立。

## 审查重点

1. 是否接受“笛卡尔和加性嵌套码本”作为第一版嵌套参数化；若容量损失超过 1%，再比较层次树码本或增加残差阶段容量。
2. 排序门是否应要求 `Spearman >= 0.8` 且“独立短适配最优候选位于共享 Top-K”；当前实现采用这两个条件。
3. 外层 winner 监督更新是否可作为第一版双层近似；若要求理论超梯度，需要另增 one-step unroll 或隐式微分路径。
4. 是否先只运行容量门，通过后才允许排序门和双时间尺度门；当前脚本按此顺序设计，第三道门强制读取前两门的 PASS JSON。
