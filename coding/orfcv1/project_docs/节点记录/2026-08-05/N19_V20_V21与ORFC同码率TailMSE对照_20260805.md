## 结论

1. `blk20-R64/R96` 在日志交叉比较中看似落后，但严格同图比较后均小幅优于 ORFC，说明几个百分点的跨数据集差异不能解释为方法差异。
2. `blk20-R512` 的 Tail MSE 改善幅度较大，在严格同图口径下达到 17.87%。
3. `blk05/10/15-R64/R96` 与 `blk20-R128/R256` 的现有日志方向总体积极；严格结论仍需把双方冻结 checkpoint 放到同一 ImageNet-500 上评测。
